How to extract pages from a PDF online

A PDF page extractor lets you create a smaller PDF containing only the pages you need. This can be useful for sharing a section of a report, separating an appendix, preparing selected forms, or creating a focused document from a longer PDF.

How to select PDF pages by range

The page range box accepts individual page numbers and inclusive ranges. Separate each selection with a comma. Page numbering starts at 1, which represents the first page of the PDF. 

1       Extract the first page
1-3     Extract pages 1, 2, and 3
2,5,8   Extract pages 2, 5, and 8
1-3,7   Extract pages 1, 2, 3, and 7
5-8,1   Extract pages 5 through 8, then page 1

The tool removes duplicate selections and reports the issue. When preserve-order mode is enabled, it keeps the order of the ranges you enter; otherwise, pages are sorted by page number.

When should you use a PDF page extractor?

  • Reports and research: extract a selected chapter, appendix, or set of pages.
  • Business documents: create a separate document containing the pages relevant to a particular task.
  • Forms and applications: save the specific pages you need to review or share.
  • Study materials: create a smaller PDF with selected pages from a longer document.
  • Odd or even pages: extract one page-number group from a document for certain printing or review workflows.

Are my PDF files uploaded to a server?

The selected PDF is read and processed in your browser using JavaScript. The tool does not upload the PDF to our server. The PDF processing library is loaded from a CDN, so an internet connection is required when the library has not already loaded.

Browser-based processing reduces the need to send a document to a remote PDF service, but it is not a guarantee against access by browser extensions or other software running on your device. Avoid using an untrusted device for confidential files.

Important PDF extraction limitations

  • This version supports files up to 50 MB and limits each extracted output to 1,000 pages to help manage browser memory.
  • Password-protected or encrypted PDFs may not open. Remove protection only when you have permission to do so, using a compatible trusted tool.
  • Extracting pages does not reliably preserve document-level features such as all bookmarks, interactive form behavior, digital signatures, or every type of metadata.
  • Extracting pages is not the same as redacting information. Content that appears hidden or covered may remain in a PDF's underlying data.
  • The tool preserves the selected pages' visual content as copied by the PDF library. It does not convert them into editable text, perform OCR, or guarantee that every unusual PDF structure can be copied successfully.

Frequently asked questions

How do I extract specific pages from a PDF?

Upload your PDF, enter page numbers or ranges such as 1-3, 5, or 8-10, check the selected pages, and click Extract selected pages. Download the resulting PDF when processing finishes.

Is this PDF page extractor free?

Yes. This page lets you select, extract, and download PDF pages without a tool usage fee or an account.

Can I extract multiple nonconsecutive pages?

Yes. Enter page numbers and ranges separated by commas. For example, 1-3, 6, 9-10 selects pages 1, 2, 3, 6, 9, and 10.

Can I change the order of extracted pages?

Yes. Keep preserve-order mode enabled and enter ranges in the order you want them to appear in the output. Turn it off to put selected pages in ascending page-number order.

Does extracting pages reduce PDF file size?

It may, because pages you do not need are omitted. The exact size depends on embedded resources and PDF structure; this tool is not a dedicated PDF compressor.

Are my PDF files uploaded?

No. The PDF is processed locally in your browser by this tool. The processing library is loaded from a CDN, but the selected PDF file itself is not uploaded to our server.

Can I extract pages from a password-protected PDF?

Password-protected or encrypted PDFs may not be supported by this version. If you are authorized to access the file, use a suitable trusted PDF application to produce an accessible copy before trying again.

Does extraction remove hidden or sensitive information?

No. Page extraction is not a redaction tool. Information in selected pages can remain present even if it appears hidden or visually covered. Use a dedicated redaction workflow for sensitive information.

Why did my PDF fail to load?

The file may be damaged, encrypted, unsupported, larger than the file limit, or too complex for your browser's available memory. Try a valid PDF and close other resource-intensive browser tabs if necessary.

Does the output keep bookmarks and digital signatures?

Not necessarily. Creating a PDF from copied pages may not preserve every document-level feature, interactive form, bookmark, or digital signature. Check the result carefully if your document depends on those features.
