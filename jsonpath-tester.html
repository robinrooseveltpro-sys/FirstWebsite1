What is JSONPath?

JSONPath is a query language for selecting values from JSON documents. It is often compared with XPath, which selects nodes from XML. JSONPath is especially useful when a response contains deeply nested properties or arrays and you need a smaller selection without manually navigating every object.

Common JSONPath expressions

  • $ selects the root document.
  • $.user.name selects the name property inside user.
  • $.users[*].email selects the email property of each user.
  • $..id searches recursively for properties named id.
  • $.items[0] selects the first array item.
  • $.items[?(@.price < 10)] selects items whose price is below 10 in the supported filter dialect.
  • $.items[0:3] selects a range of array elements supported by the implementation.

What does recursive descent mean?

The .. operator searches at deeper levels of the document. For example, $..price can find price properties inside several different objects, not just at the root or one fixed nesting depth. By contrast, $.* selects only direct children of the root.

Why does a query return zero matches?

A query can be syntactically valid while selecting nothing. The property may not exist, an array index may be out of range, or a filter may exclude all records. A malformed expression usually produces a query error instead.

JSONPath compatibility

JSONPath was standardized in RFC 9535, but popular implementations retain different historical features and filter syntax. This page uses JSONPath-Plus and its supported extensions. Do not assume that every query behaves identically in every programming language or strict RFC 9535 implementation.

Privacy and performance

The JSON document is parsed and queried in your browser; the page does not send your JSON to a query endpoint. The JSONPath library is loaded from a CDN. Large documents and recursive or broad queries can use substantial memory or processing time, so this page limits input size and the number of results shown.

Frequently asked questions

How do I test a JSONPath expression online?

Paste a JSON document, enter an expression such as $.users[*].email, and select Run JSONPath. The tool displays matching values and their paths.

What is the difference between JSONPath and JSON Pointer?

JSONPath is a query language that can select multiple values using wildcards and filters. JSON Pointer identifies a single location through a sequence of path segments. This tool displays JSONPath-style matched locations.

Can JSONPath filter array elements?

Yes. JSONPath-Plus supports filter expressions such as $.users[?(@.active == true)]. Filter syntax and semantics can differ between implementations.

Why is the result empty instead of showing an error?

An empty result can mean a valid query did not find the requested property or did not find any values satisfying the filter. The tool distinguishes this from many syntax and parsing errors.

Does this tool support the official JSONPath standard?

The page uses JSONPath-Plus, which implements the original JSONPath style and adds extensions. Some syntax differs from strict RFC 9535 semantics, so confirm compatibility with your target runtime.

Are my JSON files uploaded?

The page reads the JSON locally and evaluates the query inside your browser. It does not include a JSON upload endpoint. The JavaScript library is loaded from a CDN.

Can I download just the matching values?

Yes. Use Copy values as JSON or Download values to export the matched values as a JSON array. You can also export the path for each match as a separate text file.
