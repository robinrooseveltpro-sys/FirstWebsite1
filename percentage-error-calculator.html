How to calculate percentage error

Percentage error describes the absolute difference between a measured result and a known accepted or reference value, relative to the magnitude of that reference value. It is often used in laboratory experiments and scientific measurements.

Absolute error

The absolute error is the magnitude of the difference between the measured value and the accepted value. It is expressed in the same units as the original measurements.

Relative error

Relative error is the absolute error divided by the magnitude of the accepted value. It has no units and shows the error relative to the reference.

Percentage error

Percentage error is the relative error multiplied by 100. For a nonzero accepted value, it expresses the absolute error as a percentage of the reference magnitude.

Percentage error formula

Absolute error = |Measured value − Accepted value| Relative error = Absolute error ÷ |Accepted value| Percentage error = Relative error × 100%

The absolute value bars mean that ordinary percentage error is nonnegative. This calculator uses the magnitude of the accepted value in the denominator, which also permits negative nonzero reference values.

Worked example

Suppose an experiment measures a value of 9.8 while the accepted reference value is 9.81. The absolute difference is 0.01.

Absolute error = |9.8 − 9.81| = 0.01 Percentage error = (0.01 ÷ 9.81) × 100 ≈ 0.1019%

The measured result is below the accepted reference in this example. The magnitude of the percentage error is approximately 0.1019%. The signed percentage error is approximately −0.1019%.

Important: Percentage error requires a nonzero accepted reference value. If no accepted value exists and you are comparing two measurements of equal standing, percentage difference may be more appropriate. The average percentage error across trials is an arithmetic average of the individual errors; it is not the same as calculating the percentage error of an average measurement.

Frequently asked questions

What is a percentage error calculator?

It calculates the absolute error, relative error, and percentage error between a measured value and a nonzero accepted reference. This version also compares multiple trials, gives step-by-step calculations, and supports exporting the results.

What is the formula for percentage error?

Percentage error equals the absolute difference between the measured and accepted values divided by the magnitude of the accepted value, multiplied by 100. Absolute value bars make the result nonnegative.

Can percentage error be negative?

Standard absolute percentage error is not negative. However, signed percentage error can be negative or positive and indicates whether the measured value is below or above the accepted value numerically.

Why can't the accepted value be zero?

Percentage error divides by the magnitude of the accepted value. When that reference is zero, the calculation involves division by zero and the percentage error is undefined. Use a different suitable measure if the reference is zero.

What is the difference between percentage error and percentage difference?

Percentage error normally compares a measurement with a recognized reference value. Percentage difference is commonly used to compare two measurements when neither is designated as the accepted reference. Their formulas and interpretations are not interchangeable.

Can I calculate percentage error for multiple trials?

Yes. Add a row for each trial and enter its measured value and accepted reference value. The calculator reports each error, the mean absolute percentage error, and additional aggregate statistics. Use consistent units and the same kind of physical quantity when interpreting the averages.

Does a lower percentage error always mean a better experiment?

A lower percentage error indicates a closer match to the reference under this measure. It does not, by itself, establish that the experiment was well designed, that the reference is correct, or that uncertainty and systematic errors are absent.

Are my measurements sent to a server?

The calculator's calculations, copying, and CSV generation run in your browser. This page's tool code does not send measurement values to a calculation server. Separately configured hosting, analytics, or advertising services may have their own data practices.
