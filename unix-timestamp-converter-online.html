What is a Unix timestamp?

A Unix timestamp, also known as epoch time, Unix time or POSIX time, represents a point in time as the number of seconds elapsed since the Unix epoch: January 1, 1970, at 00:00:00 UTC. This convention is widely used by applications, APIs, databases, operating systems and programming languages.

Example: The Unix timestamp 0 represents 1970-01-01 00:00:00 UTC. The number represents the same instant regardless of the timezone used to display it.

Unix timestamp seconds vs. milliseconds

Unix timestamps are commonly represented in seconds or milliseconds. A current timestamp in seconds often has 10 digits, while a millisecond timestamp often has 13 digits. Microsecond and nanosecond timestamps are usually longer. These are patterns, not absolute rules: old dates, far-future dates and custom systems can make the unit ambiguous. When the unit matters, select it manually.

What is epoch time to date conversion used for?

An epoch converter is useful when reading API responses, checking database records, comparing server logs, reviewing event timestamps, debugging applications or converting dates for scheduled tasks. The terms timestamp to date, epoch time to date, Unix time converter and Unix timestamp conversion often describe the same basic task.

Unix timestamp examples in programming

Different programming environments provide their own methods for working with epoch values. The examples below show common ways to obtain the current Unix timestamp.

JavaScript
// Current Unix timestamp in seconds
Math.floor(Date.now() / 1000)

// Current timestamp in milliseconds
Date.now()
Python
import time
from datetime import datetime, timezone

# Current Unix timestamp in seconds
timestamp = int(time.time())

# Convert a timestamp to a UTC date
date = datetime.fromtimestamp(timestamp, tz=timezone.utc)
PowerShell
# Current Unix timestamp in seconds
[DateTimeOffset]::UtcNow.ToUnixTimeSeconds()

# Convert a Unix timestamp back to a UTC date
[DateTimeOffset]::FromUnixTimeSeconds(1735689600).UtcDateTime
Linux or macOS terminal
# Current Unix timestamp in seconds
date +%s

Frequently asked questions

Quick answers about Unix timestamps and epoch conversion.

What is the difference between Unix time and epoch time?

They commonly refer to the same convention: counting time from January 1, 1970, at 00:00:00 UTC. “Unix timestamp” and “epoch timestamp” are also frequently used interchangeably.

How do I convert a Unix timestamp to a human-readable date?

Enter the timestamp, select its unit if necessary, and press Convert timestamp. The results include readable dates, ISO 8601, UTC and the selected timezone.

How do I convert a date to a Unix timestamp?

Choose a date and time in the Date to timestamp section. Select the timezone that applies to the date, then press Convert date. The tool returns the corresponding epoch values.

How can I tell whether a timestamp is in seconds or milliseconds?

Current timestamps commonly use 10 digits for seconds and 13 digits for milliseconds. This is only a useful clue, not a guarantee. Select the intended unit manually if you know it or if the conversion looks incorrect.

What is the Unix timestamp for January 1, 1970?

The start of the Unix epoch is timestamp 0, corresponding to January 1, 1970, at 00:00:00 UTC.

Can I convert timestamps from different timezones?

Yes. A Unix timestamp identifies an instant, and this tool can display that instant in UTC, your browser's local timezone or one of the available timezones. When creating a timestamp from a date, the selected timezone determines how that wall-clock date is interpreted.

Can I convert many Unix timestamps at once?

Yes. Use the batch converter to enter one timestamp or date per line. Convert the list and copy the CSV result or download it for use in a spreadsheet.

Are my timestamps uploaded to a server?

No. Conversion is performed in your browser by this page's JavaScript. The conversion itself does not send the timestamp values you enter to a conversion API.
