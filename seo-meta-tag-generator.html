SEO title tags and meta descriptions

What is an SEO title tag?

A title tag provides a page title in the document's HTML head. Search engines can use it when forming a search-result title link, but they may choose other information from the page or links to it. Write titles that are descriptive, distinctive, and consistent with the visible page heading.

What is a meta description?

A meta description summarizes what a webpage contains. Search engines may use it in a result snippet when it helps describe the page, but they can also generate a snippet from the page's visible content. A useful description should explain the page clearly and give a person a genuine reason to visit.

Are character limits fixed?

No universal character count guarantees that a title or description will be displayed in full. Search-result layouts can truncate text according to device width, query, and other factors. The counters here are editing aids, not hard ranking requirements.

Canonical URLs and indexing directives

What is a canonical URL?

A canonical link identifies the preferred URL for substantially duplicate or similar pages. It should point to a real, appropriate page URL. It is not a general way to force a page into Google's index, and it should not be set to an unrelated destination.

What do index and noindex mean?

Indexing directives communicate whether a page should be eligible for indexing and whether links on it should be followed. Do not apply noindex accidentally to a page intended to appear in search results. Directives work only when crawlers can access and process the page; they cannot compensate for blocking the page from crawling.

Open Graph and Twitter metadata

Open Graph tags describe a webpage for social-sharing previews. Common fields include the social title, description, page URL, type, and image. Twitter card metadata provides corresponding hints for compatible X/Twitter previews. The final appearance depends on each platform's crawler, rules, image requirements, and cache.

Use a publicly accessible absolute image URL for a social preview image. An image that exists only on your computer cannot be fetched by a social platform when it crawls the published webpage.

Where do you put the generated meta tags?

Add the generated metadata inside the appropriate webpage's <head> element. Do not paste a second complete HTML document or create duplicate conflicting canonical and title tags. If the page already has metadata, update or replace the existing tags as appropriate. 

<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Your page title</title>
  <meta name="description" content="A clear page summary.">
  <link rel="canonical" href="https://example.com/page/">
</head>
<body>
  <h1>Your visible page heading</h1>
</body>
</html>

Frequently asked questions

Is this SEO meta tag generator free?

Yes. You can generate, preview, copy, and download the metadata on this page without an account or a tool usage fee.

Will these meta tags improve my Google rankings?

Correct metadata can help describe a webpage, and good titles can help people understand a search result. However, generating tags does not guarantee rankings, indexing, clicks, or traffic. Overall page usefulness, technical accessibility, content quality, competition, and many other factors matter.

Does Google always show my meta description?

No. Google may create a snippet from the page's visible content when it considers that content more useful for a particular search. A meta description is a suggestion, not a guaranteed search-result snippet.

How long should an SEO title be?

Write a concise title that accurately describes the page. There is no fixed character limit that guarantees full display; title links may be truncated or rewritten depending on the search result and device.

What is a canonical URL used for?

A canonical URL indicates the preferred URL among duplicate or substantially similar pages. Choose a valid URL that represents the intended primary version of the page.

What are Open Graph tags?

Open Graph tags provide information such as title, description, URL, type, and image to help compatible platforms build a social-sharing preview.

Can I use this tool on a phone?

Yes. The form, previews, and HTML output are designed to adapt to smaller screens. You can edit the fields and copy the code using a supported mobile browser.

Do I need to add the metadata to every page?

Each important page should have metadata that accurately describes that specific page. Avoid using identical titles and descriptions across unrelated pages.

Where do I paste the generated code?

Place the relevant generated tags inside the head section of the webpage they describe. Review the existing HTML first to prevent duplicate or conflicting metadata.
