What is a CSS gradient?

A CSS gradient is a smooth transition between two or more colors. It is generated by the browser, so a simple gradient does not require you to create or download a background image. Gradients are commonly used for hero sections, buttons, cards, banners, decorative surfaces, and web application interfaces.

Linear gradients

A linear gradient blends colors along a straight line. Its direction can be expressed as an angle or a keyword such as to right. Use linear gradients for hero backgrounds, buttons, banners, and horizontal or diagonal transitions.

Radial gradients

A radial gradient spreads colors outward from a central point. It can be circular or elliptical and can be positioned away from the center of an element. This makes radial gradients useful for glows, spotlight effects, soft decorative backgrounds, and layered interface designs.

Conic gradients

A conic gradient transitions colors around a central point. You can use it to create color-wheel effects, decorative badges, circular illustrations, and other designs that benefit from a rotational color transition.

What are color stops?

A color stop defines a color and where it appears along a gradient. For example, a stop at 25% places its color a quarter of the way through the gradient's progression. Multiple stops provide control over the transition, allowing you to create more complex blends than a simple two-color gradient.

Why generate CSS instead of using a background image?

CSS gradients are scalable and can be adjusted in code without creating a separate image for each variation. They are convenient for responsive layouts and interface components. Complex artwork, detailed textures, or photographic backgrounds may still need image assets.

How do I use the generated CSS?

Copy the complete CSS rule and place it in your stylesheet. You can use it in the background property of a button, card, section, or other HTML element by adjusting the selector to match your project.

What is the difference between CSS and Tailwind output?

The CSS output is a standard background declaration. Tailwind output uses an arbitrary background utility class. Tailwind projects must include the class in a source file scanned by the build process.

Can I use these gradients on commercial websites?

You can use generated CSS in your projects, including commercial projects. Check any separate assets, fonts, or other design materials you combine with it for their own licensing terms.
