What this tool does and does not do

  • It queries a single resolver at a time. Cloudflare is the default, Google is the alternative. Results reflect that resolver's cache and location, not every nameserver worldwide.
  • It does not check DNS propagation across multiple regions. For that, use a propagation checker, which is a different tool.
  • It runs entirely in your browser. The domain you type is sent to Cloudflare or Google, not to this site. Nothing is logged by this page.
  • Public DNS-over-HTTPS endpoints have rate limits. The "look up all common records" button adds a small delay between queries to be gentle, but heavy repeated use can be blocked by the resolver.
  • Records are cached by the resolver for their TTL. If you just changed a DNS record and this tool still shows the old value, that is the cache, not a bug.

What is a DNS lookup?

A DNS lookup asks a domain name system resolver what records exist for a domain. You give it a name like example.com and a record type, and it returns the records of that type. The most common is A, which maps a name to an IPv4 address. AAAA does the same for IPv6. MX lists mail servers. TXT holds text data used for verification, SPF, DKIM, and other purposes. NS lists the nameservers for the domain.

What record types can this tool query?

A, AAAA, CNAME, MX, TXT, NS, SOA, and CAA. If you need SRV, PTR, DS, DNSKEY, or a type not on this list, use the command line tool dig or drill, or a resolver that supports arbitrary types.

What is DNS-over-HTTPS?

DNS-over-HTTPS, or DoH, is a way to send DNS queries over an encrypted HTTPS connection instead of plain UDP port 53. Cloudflare and Google both run public DoH endpoints that return JSON. This tool uses those JSON endpoints so the lookup can happen directly in your browser without any server of ours involved.

Does this tool store or log my queries?

This page has no backend and no analytics on the query itself. The domain you enter is sent by your browser directly to Cloudflare or Google. Those providers have their own logging policies. If the domain is sensitive, use a resolver you control.

Why do I get different results than from my terminal?

Your terminal uses whatever resolver your system is configured to use, often your ISP or a local caching resolver. This tool uses Cloudflare or Google directly. Caches differ, and some resolvers apply filtering. Different answers usually mean one of the caches has a fresher or older copy of the record.

Can this tool check DNS propagation?

No. Propagation checking means querying many resolvers in many regions and comparing answers. This tool queries one resolver at a time. If you need propagation, use a dedicated propagation checker.

Why does a lookup sometimes fail?

The most common causes are: the domain does not exist, so the resolver returns NXDOMAIN; the public DoH endpoint rate-limited or blocked your network; or the browser blocked the request. The tool shows an error message for each of these cases. Try the other resolver or wait a minute before retrying.
