What is a Unix timestamp?

        

          A Unix timestamp represents the elapsed time since
          January 1, 1970, 00:00:00 UTC, the Unix epoch. Traditional Unix
          timestamps are expressed in seconds, while many programming
          languages and APIs use milliseconds. The unit matters: interpreting
          milliseconds as seconds, or vice versa, can produce a completely
          incorrect date.
        


        
What is the difference between seconds and milliseconds?

        

          A timestamp in seconds counts whole or fractional seconds from the
          epoch. A timestamp in milliseconds counts thousandths of a second.
          For example, JavaScript's Date.now() returns milliseconds,
          while Math.floor(Date.now() / 1000) returns whole seconds.
          Auto-detection is a useful shortcut, but explicitly choosing the unit
          is safer for unusually old or far-future dates.
        


        
What is ISO 8601?

        

          ISO 8601 is a widely used format for representing dates and times.
          A UTC value often looks like
          2026-10-16T04:00:00.000Z. The trailing
          Z indicates that the time is expressed in UTC.
          This format is especially convenient when inspecting APIs, logs,
          databases, and application data.
        


        
Why does the same timestamp show different times?

        

          A timestamp identifies the same instant regardless of where it is
          viewed. The displayed clock time changes with the timezone.
          For example, UTC and Kathmandu use different UTC offsets. Daylight
          saving rules can also affect the displayed time in some locations.
          Compare the UTC and selected-timezone outputs when troubleshooting
          an application.
        


        
Where are timestamps used?

        

          Developers encounter Unix timestamps in API responses, database
          records, authentication tokens, server logs, analytics events,
          scheduled jobs, and application debugging. Converting them into
          human-readable dates makes it easier to inspect event times and
          identify inconsistencies.
