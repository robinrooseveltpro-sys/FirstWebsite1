How to convert YAML to JSON

YAML is often used for human-readable configuration files, while JSON is common in APIs, web applications, and data exchange. This free YAML to JSON converter parses your YAML and creates JSON output you can copy or download.

YAML to JSON example

Here is a simple configuration and the equivalent JSON structure.

Input YAML

app:
  name: Demo API
  port: 8080
  enabled: true
features:
  - login
  - reporting

Output JSON

{
  "app": {
    "name": "Demo API",
    "port": 8080,
    "enabled": true
  },
  "features": [
    "login",
    "reporting"
  ]
}

YAML indentation defines nested data. JSON represents the resulting mappings as objects and sequences as arrays. The values are parsed according to the YAML parser's type rules, so always review the result when converting production configuration.

Convert multi-document YAML files

A YAML stream can contain multiple documents separated by a line containing three hyphens (---). This is common in configuration bundles, including some Kubernetes manifest files. When multiple documents are detected, this tool produces a JSON array with one entry per document. 

---
name: frontend
replicas: 2
---
name: backend
replicas: 3

The resulting JSON is an array containing both document objects. If the input contains just one YAML document, the result is that document's JSON value rather than a one-item array.

Features of this YAML to JSON converter

YAML syntax validation

If the parser encounters invalid YAML, the tool displays the parser's explanation and line and column information when available. Duplicate mapping keys and indentation mistakes can cause parse errors.

Formatted or minified JSON

Choose two-space indentation for a readable document, four-space indentation for deeper visual separation, or minified JSON when you want fewer whitespace characters.

File upload and download

Load a YAML text file without manually copying its contents. After conversion, download the resulting JSON file or copy it to another application.

Browser-based processing

The conversion happens in your browser using a JavaScript YAML parsing library. The YAML text you enter and the file you select are not uploaded to our server by this tool. The parser library itself is loaded from a CDN, so an internet connection is needed when the page first loads it.

Important conversion details

  • JSON does not support YAML comments, so comments are not preserved in the JSON output.
  • YAML supports types and structures that JSON cannot represent directly. Special values, timestamps, and complex mapping keys deserve extra review after conversion.
  • YAML anchors and aliases may be resolved into repeated JSON structures. Recursive references cannot be represented as ordinary JSON and may cause conversion to fail.
  • When multiple YAML documents are supplied, the converter returns a JSON array. Check whether the application receiving your JSON expects an array or a single object.
  • The maximum input size is 2 MB. Very deeply nested or unusually complex documents may still take longer to process.

When should you convert YAML to JSON?

Developers commonly convert YAML when a tool, endpoint, or application expects JSON rather than YAML. Typical examples include inspecting API payloads, adapting configuration files, checking nested data, and preparing structured values for a JSON-based workflow.

This browser converter is best suited to one-off or occasional conversion. For automated build pipelines or repeated batch jobs, a local command-line utility or programming library may be more appropriate.

Frequently asked questions

How do I convert YAML to JSON online?

Paste your YAML into the input editor or upload a YAML file. Select Convert YAML to JSON, check the generated output, and copy it or download it as a JSON file.

Is this YAML to JSON converter free?

Yes. The converter on this page can be used without a tool usage fee or an account.

Are my YAML files uploaded to a server?

The YAML parsing and JSON generation run in your browser. The selected YAML file and the text you enter are not uploaded to our server by this tool. The page loads its parser library from a CDN.

Can I convert a YAML file with multiple documents?

Yes. Documents separated by YAML document markers are parsed individually and returned together as a JSON array.

Why does my YAML produce a syntax error?

Common causes include incorrect indentation, a missing colon, mismatched quotation marks, malformed lists, or duplicate mapping keys. Read the reported parser message and inspect the indicated line and column.

Are YAML comments preserved in JSON?

No. Standard JSON has no comment syntax. YAML comments are therefore omitted during conversion.

Does converting YAML to JSON change data types?

It can. YAML and JSON do not have exactly the same type system, and the parser interprets values according to its YAML schema. Inspect dates, special values, keys, and configuration values before using the output in a production application.

Can I convert JSON back into YAML with this tool?

This page focuses on YAML to JSON conversion. It does not currently provide a JSON to YAML conversion mode.

What is the maximum file size?

This version accepts input up to 2 MB. Large or deeply nested files may still be affected by your device's available memory and browser performance.
