What is a HAR file?

HAR stands for HTTP Archive. A browser's developer tools can export a HAR file containing a record of network requests made while a page loads. Depending on the capture, it may include request URLs, HTTP methods, response status codes, headers, timing measurements, cookies and text or binary payloads.

How to open a HAR file

  1. Open the browser's Developer Tools and select the Network panel.
  2. Reproduce the issue or reload the affected page.
  3. Use the browser's export or save-network-log option to save a HAR file.
  4. Open the file here and review failed requests, long durations and request details.

How to investigate slow requests

Filter the capture to find requests taking at least one second, then compare their URLs, status codes, response sizes and recorded durations. HAR timing measurements can contain phases such as DNS lookup, connection setup, waiting and receiving. Some phase values can be absent or negative when not available in the capture.

Why should you redact a HAR before sharing?

Captures can contain credentials, cookies, session identifiers, personal data and confidential request or response bodies. A redacted capture can be safer to share for troubleshooting, but no automated filter can reliably detect every kind of confidential value in arbitrary text.

What does this tool redact?

The redactor can mask common authentication headers, cookie values, credential-like query parameters and recognized key names in JSON or form-encoded bodies. It removes body text by default. Unknown field names, encoded data, custom formats, free-form text and secrets embedded in unexpected locations may still need manual inspection.

What are the limitations?

This is a lightweight HAR viewer rather than a full browser network debugger. It does not replay requests, access live network traffic, validate application behavior, or guarantee full HAR schema compliance. Timing and size fields are shown as recorded; unavailable values are not treated as measured values.

Frequently asked questions

How do I open a HAR file online?

Choose a HAR file or paste its JSON into the input box, then select Parse HAR. The viewer displays request methods, URLs, status codes, recorded sizes and durations.

Does this tool upload my HAR file?

No. The page reads the file in the browser and does not send the capture to this website's conversion server. Other browser extensions, page scripts or device monitoring software are outside the scope of this tool.

Can a HAR file contain passwords or session cookies?

It can contain authentication headers, cookies, query parameters, request bodies and response data. Treat the original capture as sensitive and inspect any redacted export before sharing.

Can I export HAR requests to CSV?

Yes. Apply your filters and select Export filtered CSV. The exported request URLs mask common credential-like query parameter values.

Why is a response body missing?

Some HAR captures omit response bodies, and others contain only metadata or encoded binary content. The viewer cannot reconstruct information that was never captured.

Does redacting a HAR guarantee that it is safe to share?

No. Automated redaction detects common patterns only. Review URLs, custom headers, text fields and any included bodies carefully before sharing a capture externally.
