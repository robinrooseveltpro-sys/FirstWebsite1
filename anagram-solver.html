What is an anagram?

An anagram is a word or phrase formed by rearranging the letters of another word or phrase, using every letter exactly once. Listen and silent are anagrams. So are Dormitory and dirty room.

How this solver works

The core trick is a letter signature. Every dictionary word is converted to its letters sorted alphabetically — listen becomes eilnst. Two words are anagrams if and only if their signatures match, so single-word anagram solving becomes a single dictionary lookup instead of a permutation search.

Multi-word solving is harder. The solver uses recursive backtracking over a letter-count vector: it picks a dictionary word whose letters fit inside the remaining letters, subtracts them, and recurses until the letters run out. To avoid returning the same phrase in a different order, it only accepts words that come after the previous word alphabetically. The search has a 3-second budget, so it stays responsive on large inputs.

Wildcards

? stands for exactly one unknown letter. * stands for zero or more. Examples: L?STEN, LIST*, *ING, C?T. Wildcards are matched as a pattern against the dictionary rather than by permutation, so they stay fast with several unknown letters.

Scoring

Every result shows both Scrabble and Words With Friends scores, because the two games value letters differently. Scrabble rewards J, X, Q, and Z at 8–10 points; Words With Friends scores H, V, and W higher.

About the dictionary

The solver loads the ENABLE word list, roughly 173,000 English words, in the public domain. It is the de-facto standard for free Scrabble software and online word games. If the network request fails — offline, blocked, or slow — the tool falls back to a built-in list of common words and reports which list is active in the status line.

Limitations

  • Fixed dictionary. Proper nouns, brand names, and very recent slang are not included.
  • Multi-word capped at four words, with a 3-second time budget so the page stays responsive.
  • Wildcard patterns matched literally. ?? matches every two-letter word — a very large list.
  • Voice input depends on the browser. Chrome, Edge, and Safari 14.1+ support it; Firefox has it disabled by default, and the button hides itself when unavailable.
  • No definitions. The tool tells you which words exist and what they score.

Frequently asked questions

What is the best way to solve an anagram?

Start with vowels and common consonant clusters, then look for suffixes like -ing, -tion, and -ed. A solver short-circuits that: type the letters and it returns every dictionary match instantly, including multi-word phrases that are hard to spot by hand.

Does this solver handle multi-word anagrams?

Yes. Switch to Multi-word mode. It uses recursive backtracking to find phrases of two to four words that use all the letters.

How do wildcards work?

Use ? for one unknown letter and * for zero or more. For example L?STEN matches six-letter words with an unknown second letter, and *ING matches any word ending in ING.

Is this Scrabble-compliant?

It uses the ENABLE word list, the standard for free Scrabble software. Official tournament Scrabble in North America uses the separate TWL list, similar but not identical.

Does it work offline?

Yes, with the built-in fallback dictionary. The full ENABLE list is fetched on first load and cached; if that request fails, the tool uses the smaller list and reports it.

Does voice input work in every browser?

No. Chrome, Edge, and Safari 14.1+ support the Web Speech API; Firefox has it disabled by default. The Speak button hides itself when the API is unavailable.

Can I use this to make an anagram of my name?

Yes — one of the most common uses. Type your name without spaces, switch to Multi-word, and raise the result limit.

Is my input uploaded anywhere?

No. The letters you type are processed in the page. The only network request is the one that fetches the public dictionary file.
