How to read a text comparison

Added lines

Green highlighting identifies lines present in the revised text that do not match an equivalent line in the original under your chosen comparison settings.

Removed lines

Red highlighting identifies lines in the original that no longer have a matching line in the revised version.

Word and character highlights

In word-level and character-level modes, paired changed lines can show smaller highlighted sections inside a line. This makes it easier to find a renamed variable, changed number, edited sentence, or altered configuration value.

When should you ignore whitespace or case?

Ignore whitespace differences

This option collapses whitespace runs for matching purposes. It can reduce noise caused by spacing or indentation changes, particularly in prose and some configuration comparisons. It can also hide meaningful changes in languages where spaces affect syntax, so use it only when appropriate.

Ignore case differences

Case-insensitive comparison treats uppercase and lowercase versions of a line as equivalent. This helps when reviewing text where letter case is not important, but can conceal changes to case-sensitive code, filenames, identifiers, or credentials.

Ignore blank lines

This removes blank lines from the comparison sequence. Use it to focus on content rather than vertical spacing. The display still uses original line numbers, but omitted blank lines will not be highlighted as differences.

What can you compare with a text diff checker?

  • Documents and drafts: review edits to articles, emails, policies, and written content.
  • Source code: compare small code snippets or file versions when reviewing a change.
  • Configuration files: detect changes to settings, environment values, and deployment configuration.
  • Data and logs: inspect differences in text exports, CSV content, application logs, and plain-text reports.
  • Structured text: compare JSON, YAML, XML, Markdown, and other text-based formats without needing to parse their data structures first.

Are my files uploaded to a server?

Text comparison is performed in your browser. The files you select are read locally, and their contents are not uploaded to our server by this tool. The page does not save a comparison history to a remote account.

The tool is intended for plain-text files, not binary documents such as PDFs, Word files, or images. Do not treat a browser tool as a complete security boundary: extensions or other software operating on your device may have separate access to its content.

Important limitations

  • The tool compares text sequences, not the semantic meaning of programming code or a document.
  • Similar or repeated lines can have more than one plausible alignment. Other comparison applications may display a different but still valid arrangement of the same changes.
  • The tool limits input size and comparison complexity to protect browser responsiveness. Large files may need to be reduced or compared in sections.
  • A successful text comparison does not guarantee that code runs, a configuration is valid, or a document is legally correct.

Frequently asked questions

What is a text diff checker?

A text diff checker compares two text versions and shows additions and removals. It is commonly used for document editing, code review, configuration checks, and content updates.

Is this text comparison tool free?

Yes. The comparison, highlighting, copy, and download features on this page are available without an account or a tool usage fee.

Can I compare text files instead of pasting text?

Yes. Use the Upload buttons to load one text file into the original panel and another into the revised panel. Supported formats include common plain-text and source-code extensions.

What is the difference between side-by-side and unified view?

Side-by-side view places the original and revised versions next to each other. Unified view combines changed lines into one column, which can be more compact on smaller screens.

Can I compare code with this tool?

Yes. Paste code or load source-code text files. The tool compares their text and does not execute the code or guarantee that the resulting version compiles.

Can I ignore spaces and capitalization?

Yes. Enable the whitespace or case options before comparing. These options affect matching, so do not use them if whitespace or letter case is significant to your code or data.

Does this tool upload my text?

No. The comparison runs in your browser and the selected text file contents are processed locally by this tool.

Why are unchanged lines hidden?

Hide unchanged lines is enabled by default so the changes are easier to find. Turn it off to display all matching lines, or select a context setting to show surrounding lines.

Why does another diff tool show different highlights?

Repeated lines can be aligned in multiple valid ways, and different comparison algorithms can choose different alignments. Ignore settings and the selected level of comparison can also affect the visual result.

Can I download a Git patch from this tool?

This version exports a readable text comparison report, not a standards-compliant unified Git patch. Use a Git diff tool if you need a patch that can be applied automatically.
