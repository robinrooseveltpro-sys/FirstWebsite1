What is CMYK?

CMYK is a subtractive color model used in commercial printing. It describes color as four ink amounts — Cyan, Magenta, Yellow, and Black (K) — measured as percentages from 0% (no ink) to 100% (full coverage). Printers layer these inks on paper, and the paper’s reflected light produces the perceived color.

What is HSL?

HSL is an additive color model designed for screens. It describes color as Hue (0–360° on the color wheel), Saturation (0–100%), and Lightness (0–100%). Because it separates the color (hue) from its intensity (saturation) and brightness (lightness), HSL is much easier to adjust by hand than RGB — which is why designers use it for CSS variables, hover states, and dark-mode variants.

Why convert CMYK to HSL?

  • A brand manual gives you CMYK print values, but your website uses CSS — you need HSL.
  • You want to adjust lightness or saturation of a print-derived color for UI states (hover, focus, dark mode), which is straightforward in HSL and painful in CMYK.
  • You are building a design-system token set and need HSL values that map cleanly to CSS custom properties.
  • You have a list of CMYK values and need them all as HSL for a component library.

How this converter works

The conversion follows the same path almost every online tool uses:

  1. CMYK → RGB using the standard formula: R = 255 × (1 − C) × (1 − K), G = 255 × (1 − M) × (1 − K), B = 255 × (1 − Y) × (1 − K), where each CMYK channel is in the 0–1 range.
  2. RGB → HSL using the standard max/min formula for hue, saturation, and lightness.
  3. RGB → HEX by converting each channel to a two-digit hexadecimal number.

The input is clamped to 0–100 for each channel, so values outside that range are corrected rather than silently producing wrong colors.

Print vs screen — an honest limitation

There is no single “correct” CMYK to HSL conversion. A true conversion requires the ICC profile of the specific press and paper stock (e.g., U.S. Web Coated SWOP, FOGRA39, Japan Color), plus a color-managed rendering pipeline. Browsers do not do ICC-profile-aware CMYK conversion in plain JavaScript.

This tool therefore uses the generic formula — the same one used by every general-purpose CMYK converter on the web. It is mathematically correct for a hypothetical ideal CMYK space and close enough for UI tokens, quick color adjustments, and cross-checking a print spec. For color-critical work, use Adobe InDesign, Illustrator, or a color-managed proofing workflow.

Frequently asked questions

Is this CMYK to HSL conversion accurate for print?

The formula is mathematically correct for a generic CMYK space, but real printed color depends on the ICC profile, paper, ink, and press conditions. This tool is accurate enough for UI tokens and quick color work, not a substitute for a color-managed proofing workflow.

Why does the swatch look different from what I expected?

Print and screen use fundamentally different color models. A “rich black” such as C60 M40 Y40 K100 often looks like a deep blue-black in print, but converts to a mid-dark blue on screen. Always compare against a physical proof for print-critical work.

Can I convert HSL back to CMYK?

This page converts CMYK to HSL only. For the reverse direction, use a dedicated HSL-to-CMYK tool or a design application with color management.

What does K mean in CMYK?

K stands for “Key,” which is the black plate in commercial printing. Using a separate black ink produces deeper, sharper blacks and saves colored ink compared with mixing C, M, and Y at full saturation.

Does batch conversion have a limit?

The batch mode accepts up to 100 colors per run. Each line must contain exactly four numbers between 0 and 100. Invalid lines are reported with their line number.

Why does the CSS export use --color-1, --color-2, etc.?

The generated block is a starting point. Rename the variables to match your design tokens (for example --brand-primary) before pasting into production CSS.

Is my data uploaded?

No. All conversion happens in your browser using JavaScript. Nothing is sent to any server.
