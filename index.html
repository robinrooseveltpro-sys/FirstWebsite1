Before you start

How these tools actually behave

Most of these are small single-purpose pages. A few things are worth knowing before you upload a file.

Where your files go

Some tools run entirely in your browser. Your file never leaves your device. Others need a server to do the work. Each tool page tells you which one it is. If you are working with a contract, an ID scan, or anything private, read the note on the page first.

Why big files fail

A 40 MB PDF will usually choke on a phone. The browser runs out of memory and the tab crashes. That is a browser limit, not a bug in the tool. Try the same file on a desktop, or split it first. Compressing an image is the same story. RAW files and multi-page scans often need something more powerful than a browser tool.

When a link or tool breaks

If a page does not load, or a button does nothing, the best thing you can do is send a short note through the contact page. Mention the tool name, the browser you are using, and what happened. That is enough to start looking into it. Reports get read in batches, sometimes slow, but always read.

Common questions

FAQ

Do I need an account or a login?

No. There is no sign-up, no email capture and no dashboard. The tools work as soon as the page loads. If a tool lets you download a result, that is a normal browser download.

Is my data uploaded to a server?

It depends on the tool. Some run entirely in your browser. Others may send the file or text to a server to process. I try to state this clearly on each tool page. If you cannot find the note and the file is sensitive, assume it may be uploaded and act accordingly.

Why did my PDF or image fail to process?

The most common reasons are file size, memory and format. Large PDFs and high-resolution images often exceed what a browser can handle. Mobile devices hit this limit sooner than desktops. Try a smaller file or a desktop computer to see if that is the cause.

Can I use the output in commercial work?

The output is yours to use. A compressed image, a merged PDF, a formatted JSON file. That part is straightforward. The only thing to keep in mind is the license of the original material. If you did not create the source file, check its license before using the result commercially.

How do I report a problem?

Use the contact page. Include the tool name, what you tried, and what happened. A screenshot helps if you can take one. I read every report, though fixes sometimes take a while to ship.

I found two pages that seem to do the same thing.

A few tools have older versions still online. For example, there are alternate Unix Timestamp pages. They are kept up so old bookmarks keep working. The version linked from this homepage is the one to use.

Is there a limit on how many times I can use a tool?

No. There is no counter and no daily limit. Use a tool as many times as you need. If a page starts failing after many uses in a row, that is usually a memory issue in the browser, not a deliberate cap.

How is the site funded?

Reader donations, and once the site is large enough to qualify, small display ads. Nothing is paywalled. The support page explains the details if you want the longer version.
