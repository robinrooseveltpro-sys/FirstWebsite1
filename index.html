Before you start

A few things worth knowing

These are small tools meant for quick jobs. Here's what to expect.

How processing works

Some tools run entirely in your browser. Others may send data to a server. Check the notes on each tool's page if you plan to use sensitive files or credentials.

File size and format limits

Large files may fail, especially on mobile. Stick to formats the tool explicitly mentions — if it says PDF, a DOCX won't work.

Something not working?

If a tool misbehaves or a link is broken, use the Contact page and describe what you tried. It helps if you mention the browser and the file type.

About the site

Why these tools exist

ConvertToToolsOnline is a small collection of converters and utilities built around tasks that come up again and again — shrinking a photo, joining a few PDFs, checking that a DNS change has gone through, and so on.

Each tool has its own page because a tool with its own page is easier to bookmark, share, and revisit. There is no account, no dashboard and no subscription. If a page isn't useful to you, close the tab — that's the whole model.

Common questions

FAQ

Do I need to install anything or create an account?

No. Every tool works from the browser. There are no accounts, no extensions and nothing to install. Some tools will let you download a result file — that's a normal browser download.

Are my files uploaded to a server?

It depends on the tool. Some tools process data entirely on your device using browser APIs. Others may send input to a server. If you're working with confidential material, read the description on the specific tool page before uploading.

Why does a conversion or upload fail?

The most common reasons are: the file is larger than the tool supports, the format isn't recognized, or the browser doesn't have enough memory (especially on mobile). Try a smaller file or a desktop browser to isolate the cause.

Do these tools work on a phone?

Yes — the whole site is responsive. Heavy file operations (large PDFs, video-sized images) still work better on a desktop because phones have less memory and slower processors.

Can I use these tools for commercial work?

The tools themselves are free to use. The output you generate — a PDF, a compressed image, a formatted JSON file — is yours, subject to whatever license the source material carries. If you need licensing details for the tool code itself, contact me.

How do I report a broken tool or a wrong result?

Use the contact page and include the tool name, what you tried, and what happened. Screenshots help. I fix issues in batches, so it may take a little while — but reports do get read.

I found two pages that do the same thing. Which one should I use?

Use the one whose description matches your task. A couple of pages have older versions still online (for example, alternate Unix Timestamp pages). These are left up so bookmarks keep working, but the version linked from this homepage is the one to prefer.
