    What is an OPML file?

    OPML stands for Outline Processor Markup Language. It is an XML-based format used to store hierarchical outlines. In everyday use, it is most commonly the file you get when you export your subscriptions from an RSS reader or podcast app — a single file containing every feed URL and folder in your account.

    The OPML specification defines a simple tree structure: an <opml> root containing a <head> and a <body>. The <body> contains one or more <outline> elements, and each outline may contain nested outlines. Every outline has a text attribute; feed outlines typically also have type="rss" and an xmlUrl attribute pointing to the feed.

    OPML vs. RSS: what is the difference?

    An RSS feed is a live stream of articles or episodes from one website. An OPML file is a bookmark list — it does not contain articles. It contains the addresses of many RSS feeds so you can move your whole subscription list from one app to another. That is why an OPML viewer shows titles and URLs, not articles.

    How to use this OPML viewer

    1. Drag an .opml or .xml file onto the drop area, or click it to browse.
    2. The file is parsed locally. You will see a tree that mirrors the folder structure in your reader.
    3. Use the search box to filter feeds by title or URL. Matching feeds remain visible even inside collapsed folders.
    4. Click a feed’s Copy button to copy its URL, or use Export JSON / Export TXT for the full list.

    What you can learn from an OPML file

    • How many feeds and folders you actually have — exports often contain more than users expect.
    • Which subscriptions are podcasts (feeds with audio or video enclosures).
    • Whether a reader exported duplicate feeds or empty folders.
    • Which OPML version the exporter used (1.0 or 2.0).

    Privacy and limitations

    • Your OPML file is read with the browser’s DOMParser and rendered locally. It is never uploaded, logged, or sent anywhere.
    • Only well-formed XML is accepted. If the file is corrupted or is not OPML, the viewer explains the problem instead of showing a broken tree.
    • Very large OPML files (thousands of feeds) are supported, but rendering may take a moment on low-end devices.
    • This is a viewer, not an editor. It does not modify, merge, deduplicate, or re-export OPML. Use a dedicated OPML editor for those workflows.
    • Podcast detection is heuristic: feeds with type="rss" and podcast-like attributes are marked as podcasts. Some apps use non-standard attributes, so the count may differ slightly from your podcast app.

    Frequently asked questions

    Is my OPML file uploaded to a server?

    No. The file is parsed and rendered entirely in your browser using JavaScript. Nothing is transmitted anywhere.

    What is the difference between an OPML file and an RSS feed?

    An RSS feed is a live stream from one site. An OPML file is a list of feed URLs and folders — a subscription list, not article content.

    Which apps export OPML files?

    Feedly, Inoreader, NewsBlur, Miniflux, The Old Reader, NetNewsWire, Reeder, Pocket Casts, Overcast, and most other RSS readers and podcast managers.

    Can I view a podcast OPML file?

    Yes. Podcast OPML files use the same structure as RSS OPML files. The viewer shows each podcast’s title and feed URL, and flags likely podcast feeds.

    Why does my OPML file show as XML?

    OPML is a subset of XML, so many apps save OPML files with a .xml extension. This viewer accepts both .opml and .xml as long as the content is valid OPML.

    Does this tool edit or merge OPML files?

    No. This is a viewer only. Editing, merging, and deduplication require a dedicated OPML editor.

    Is there a file size limit?

    There is no imposed limit, but very large files may be slow to render on low-end devices. Typical exports from major readers are small and load instantly.
